# KomitKami

**KomitKami** adalah sebuah website manajemen produksi yang dirancang untuk meningkatkan efisiensi dan ketertiban dalam proses produksi. Sistem ini membantu perusahaan atau tim produksi untuk mencatat dan memantau stok, purchase order (PO), tiket produksi, hingga kontrol user member secara terpusat dan rapi.

## ⚙️ Fitur Utama

- 🏭 **Manajemen Produksi**
  - Membantu dalam mengelola alur produksi secara lebih cepat, efisien, dan terdokumentasi.
  
- 📦 **Manajemen Stok**
  - Mencatat ketersediaan bahan baku atau barang jadi secara real-time.

- 📑 **Tiket Produksi**
  - Membuat dan mengelola tiket produksi berdasarkan PO atau input manual.

- 🧾 **Sistem Purchase Order (PO)**
  - Mempermudah pengajuan dan pengelolaan PO produk dari user member.

- 👥 **Kontrol User Member**
  - Mengatur akses, peran, dan aktivitas dari user yang terdaftar di sistem.

## 🛠️ Teknologi yang Digunakan

- **Framework**: [Laravel](https://laravel.com/)
- **Bahasa Backend**: PHP
- **Templating Engine**: Blade (Laravel)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL

## 🚧 Status Pengembangan

> Proyek ini masih **dalam tahap pengembangan aktif** hingga waktu yang belum ditentukan. Fitur dan struktur masih terus diperbarui dan disempurnakan secara berkala.

## 📌 Tujuan Proyek

- Menyederhanakan proses produksi dari awal hingga akhir.
- Meningkatkan efisiensi pencatatan stok dan PO.
- Menyediakan platform terintegrasi untuk user member dalam mengelola operasional produksi.
- Membangun sistem yang fleksibel, dapat dikembangkan, dan mudah digunakan oleh berbagai level user.
